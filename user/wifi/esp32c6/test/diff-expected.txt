# The places the own start's access stream differs from the libraries' start's by design, each with its reason,
# which tools/mac-trace.py diff --expect lets pass alone and exactly; the names are macregs.h's.
# A place is its reason, then the libraries' accesses ("-") and the own start's ("+"); a blank line ends it.
# A value "/0xmask" holds the masked bits alone: STA_ADDR_HI's and STA_ADDR2_LO's own addresses are the chip's,
# so a zero mask holds none of them.
# --as-expected, WIFI_TRACE_EXPECT_NEW=1 in make, prints a place that does not pass in this form.

# The libraries' default policy configures interface 1, the soft AP's, besides interface 0's: its address and its
# address flag; the own start writes interface 0's words alone, so the interface-1 writes, and the interface-0
# round-trips they sit among, come unmatched.
-R4 0x600a4060 0x00000000/0xffff0000
-W4 0x600a4060 0x00010000/0xffff0000
-W4 0x600a4064 0x00000000/0x00000000
-W4 0x600a4068 0x00000000/0xffff0000
-R4 0x600a4068 0x00000000/0xffff0000
-W4 0x600a4068 0x00010000/0xffff0000
-R4 0x600a40d8 0x0001c385
-W4 0x600a40d8 0x0001c385
